# نقل‌قول‌های ویرایش‌شدهٔ چهره‌ها (editorial views)

## هدف

وقتی متنِ خام صحبت/سخنرانی/گفت‌وگوی یک چهره در دست است، به‌جای پست تلگرامی،
چند **نقل‌قول منسجم** از آن استخراج و به‌عنوان «دیدگاه» در صفحهٔ همان چهره
(`#/figure/:handle`) منتشر می‌شود.

## داده کجاست

- منبع: `web-static/data/pendar-editorial-views.json`
- در هر build، تابع `merge_editorial_views` در
  `backend/scripts/build_entities.py` این نقل‌قول‌ها را داخل `figures.json`
  ادغام می‌کند و به ابتدای `posts` همان شخص می‌افزاید (بر اساس `id`).
- اگر شخص هنوز چهره نباشد، بلوک `profile` موجود در همین فایل، چهره‌اش را می‌سازد.

## روالِ نقل‌قول (قاعدهٔ ثابت)

- نقل‌قول‌ها **کامل و منسجم** باشند، نه جمله‌به‌جمله و تکه‌پاره.
- هر نقل‌قول حدوداً **۲ تا ۳ پاراگراف** و **حداکثر ۵ پاراگراف**.
- پاراگراف‌ها با یک **خط خالی** (`\n\n`) از هم جدا شوند؛ رندر وب روی همین خط خالی
  پاراگراف می‌سازد (`figureTextParagraphs`).
- چند جملهٔ هم‌موضوع در یک نقل‌قول **گروه‌بندی** شوند؛ موضوع‌های جدا → نقل‌قول‌های جدا.
- **عین کلماتِ گوینده** حفظ شود؛ فقط ویرایش نگارشی سبک و رفع خطاهای آشکارِ پیاده‌سازی.
- `summary_fa` کل متن را در یک جفت گیومهٔ بیرونی « … » می‌گیرد؛ `quote_fa` همان متن بدون گیومه.

## ساختار یک entry

```jsonc
{
  "profile": {                // فقط برای ساختن چهره در صورت نبودنش
    "handle": "...", "name_fa": "...", "role_fa": "...",
    "field": "society", "field_fa": "جامعه",
    "directory": true, "social": [], "posts": []
  },
  "posts": [{
    "id": "editorial-<handle>-<slug>",
    "handle": "<handle>", "name_fa": "...",
    "kind": "analysis",       // یا party_claim در صورت ذی‌نفع‌بودن گوینده
    "platform": "transcript", // این + editorial → پس‌زمینهٔ متمایز
    "editorial": true,
    "topic_fa": "موضوع این نقل‌قول",
    "summary_fa": "«پاراگراف ۱…\n\nپاراگراف ۲…»",
    "quote_fa": "پاراگراف ۱…\n\nپاراگراف ۲…",
    "source_name": "...", "source_note_fa": "...",
    "subject_names": ["..."], // در صورت وجود سوژهٔ مشخص
    "published_at": null, "recorded_at": "<ISO-UTC>", "url": ""
  }]
}
```

## نمایش

- چون `editorial: true` / `platform: "transcript"` است، کارت با
  **پس‌زمینهٔ گرمِ متمایز** نمایش داده می‌شود (`.fig-quote` / `.is-quote`
  در `styles.css`) تا از دیدگاه‌های تلگرامی/خبری جدا باشد.
- در سه جا رندر می‌شود: بخش دیدگاه‌ها در صفحهٔ چهره، استریم چهره‌ها، و کارت زیر خبر.
