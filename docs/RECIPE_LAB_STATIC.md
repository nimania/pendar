# آزمایشگاه رسپی — نسخهٔ استاتیک رمزگذاری‌شده

این بخش در مسیر `/recipes/` از خروجی **GitHub Pages** منتشر می‌شود.

- صفحهٔ HTML عمومی است، اما اطلاعات ۱۳ کتاب و ۳ رسپی در `data.enc.json` با AES-256-GCM رمزگذاری شده‌اند.
- کلید تصادفی ۲۵۶بیتی فقط در اختیار مالک است و **نباید** در GitHub، فایل‌های عمومی، لینک URL یا تنظیمات وب ثبت شود.
- مرورگر بعد از واردکردن کلید، داده‌ها را در حافظه باز می‌کند. کلید در localStorage، کوکی یا سرور ذخیره نمی‌شود.
- تصویر یا متن کامل کتاب‌ها در سایت قرار ندارد.
- این روش برای نمونه پژوهشی شخصی است، نه سامانه ورود کاربران؛ قابلیت لغو دسترسی به یک کاربر یا گزارش حسابرسی ندارد.
- برای افزودن داده جدید باید از منبع خصوصی Recipe Lab خروجی جدید رمزگذاری کرد و `data.enc.json` را جایگزین کرد؛ کپی JSON خام ممنوع.
- با تغییر یا افشای کلید، محتوا باید با کلید تازه دوباره رمزگذاری شود.
- اگر کلید مفقود شود، داده‌های اصلی در ریپوی خصوصی قابل بازیابی و بسته قابل بازتولید هستند.
- مسیرهای پندار دست‌نخورده باقی می‌مانند؛ فقط فولدر `web-static/recipes/` اضافه می‌شود.

## کنترل انتشار

1. فایل‌های عمومی فقط `index.html` و `data.enc.json` هستند؛ کلید و متن JSON خام نباید در گیت باشند.
2. تست مرورگر: بدون کلید اطلاعات دیده نشود؛ کلید اشتباه خطا بدهد؛ کلید معتبر ۱۳ منبع و ۳ رکورد را نمایش دهد.
3. workflow استاتیک فعلی `fast-deploy.yml` پوشه `web-static/` را در Pages overlay می‌کند.
4. پس از استقرار `https://pendar.io/recipes/` و صفحه اصلی `pendar.io` را جداگانه کنترل کن.

## ارتقای بعدی

برای مدیریت چند کاربر، استفاده تجاری و تفکیک داده‌های محرمانه، احراز هویت سمت سرور (یا edge) لازم است؛ رمزگذاری سمت کلاینت جایگزین آن نیست.
