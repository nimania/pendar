# بازبینی مطالب فناوری در چهره‌های پندار

این گردش کار **صفحه یا دیدبان جدیدی نمی‌سازد** و هیچ خروجی گردآوری‌شده را خودکار منتشر نمی‌کند.

1. اجرای GitHub Actions به نام `Collect AI figure sources for review`، فایل `ai-figure-intake.json` را به صورت artifact تولید می‌کند. خطاها در بخش `errors` ثبت می‌شوند.
2. سردبیر artifact را دریافت و برای موارد انتخابی فایل تصمیم‌ها را تهیه می‌کند. شناسهٔ `id` باید دقیقاً با صف ورودی برابر باشد. هر تصمیم تأییدشده باید `reviewer`، `topic_fa`، `summary_fa` معتبر داشته باشد.
3. اجرای `python backend/scripts/review_ai_figure_intake.py --intake ai-figure-intake.json --decisions ai-figure-decisions.json` پیش‌نمایش `ai-figure-approved-preview.json` را می‌سازد؛ این دستور داده‌های سایت را تغییر نمی‌دهد.
4. **تنها پس از بازبینی انسانی** همان دستور با `--apply` دادهٔ `web-static/data/pendar-editorial-views.json` را در نسخهٔ محلی به‌روزرسانی می‌کند. ثبت و انتشار این تغییر نیازمند کامیت مجزای بازبینی‌شده است.

نمونهٔ ساختار تصمیم:
```json
{
  "decisions": [
    {
      "id": "شناسه-صف",
      "status": "approved",
      "reviewer": "نام بازبین",
      "topic_fa": "موضوع مشخص",
      "summary_fa": "خلاصهٔ مستند و بازنویسی‌شدهٔ کافی، بدون تحریف و بدون انتساب نقل‌قول مستقیم"
    }
  ]
}
```

وضعیت‌های دیگر مانند `rejected` یا `deferred` منتشر نمی‌شوند. مرور منبع اصلی و بررسی تاریخ و انتساب به گوینده الزامی است. صفحهٔ کانال یا صفحهٔ اصلی وب‌سایت به جای پیوند مستقیم پیام پذیرفته نمی‌شود. اگر تاریخ انتشار در پیام موجود نیست، تاریخ حدس زده نمی‌شود.

محدودیت فعلی: منبع گردآوری اولیه فقط کانال‌های تلگرام معرفی‌شده در `backend/data/ai-figure-sources.json` است. پروژه‌های وب‌سایت، ایکس و رسانه‌های دیگر هنوز به گردآوری خودکار متصل نیستند. معیار انتخاب مطلب مرتبط با هوش مصنوعی در این فاز بر عهدهٔ بازبین است.
