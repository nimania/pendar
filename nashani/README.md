# نشانی کرمان — رادار اخبار شهری

این ماژول در کنار پندار اجرا می‌شود. مقصد انتشار با دریافت پیام آزمایشی از ربات و تأیید مجوز مدیریت شناسایی شد:
شناسه عددی تلگرام `-1003958286892`، عنوان دقیق «نشانی: کرمان».
در زمان استعلام، این کانال نام کاربری عمومی نداشت؛ بنابراین از `@neshanikerman` برای شناسه مقصد استفاده نمی‌شود.
نشانی عمومی `https://t.me/neshanikerman` تا بررسی اتصال آن با کانال عددی، نباید به‌عنوان لینک قطعی همان کانال معرفی شود.

## رفتار اولیه

- پایش هفت منبع: کرمان‌نو هر ۳۰ دقیقه؛ شش منبع دیگر هر ۵ دقیقه.
- هر پست متنی تازه و غیرحساس کرمان‌نو به صورت گزیده و با عبارت «به گزارش کرمان نو» منتشر می‌شود؛ موارد حساس باید تأیید شوند.
- منبع به صورت متن ساده نمایش داده می‌شود؛ لینک منبع فقط در سابقه داخلی باقی می‌ماند.
- منابع دیگر برای خبرهای شهر کرمان پایش می‌شوند؛ «کرمان رسانه» فعلاً بررسی دستی دارد.
- اجرای زمان‌بندی‌شده هر پنج دقیقه؛ تأخیر سرویس GitHub Actions ممکن است.
- تمرکز بر شهر کرمان، نه تمام استان؛ خبرهای نامطمئن وارد صف بررسی می‌شوند.
- ذخیره فقط گزیده کوتاه همراه با لینک، نه عکس و ویدئو و متن کامل.
- حذف موارد تکراری؛ رد خبر قدیمی‌تر از پنج ساعت.
- خبرهای حساس (حوادث جدی، اتهام، تلفات و غیره) فقط با تأیید دستی قابل انتشارند.
- انتشار عمومی در تنظیمات اولیه خاموش است.
- سابقه گردآوری و وضعیت انتشار در شاخه مستقل nashani-state ذخیره می‌شود.

## فعال‌سازی

۱. ربات تلگرام را با مجوز Post Messages مدیر کانال @neshanikerman کنید.
۲. در GitHub مخزن nimania/pendar، زیر Settings > Secrets and variables > Actions
یک Repository secret به نام NASHANI_TELEGRAM_BOT_TOKEN بسازید؛ توکن را در کد عمومی نگذارید.
پیش از هر ارسال، سامانه بررسی می‌کند که توکن متعلق به @neshanikermanbot باشد،
شناسه عددی و عنوان کانال واقعاً با اطلاعات تأییدشده مطابقت داشته باشند و ربات مجوز Post Messages داشته باشد.
برای آزمایش امن، در صفحه Actions همین گردش‌کار، Run workflow را اجرا و
گزینه check_connection را true کنید؛ این آزمون هیچ پستی ارسال نمی‌کند.
۳. پس از اجازه انتشار توسط مدیر، وضعیت انتشار در workflow به صورت مشروط فعال می‌شود:
تنها وقتی آزمون getMe/getChat/getChatMember موفق باشد، اخبار مطابق سیاست اختصاصی هر منبع منتشر می‌شوند.
اگر آزمون اتصال شکست بخورد، صرفاً گردآوری و صف بررسی اجرا می‌شود و هیچ پیامی ارسال نمی‌شود.
۴. اجرا و تأیید دستی از Actions > Nashani Kerman city-news radar > Run workflow انجام می‌شود.
برای تأیید یک خبر حساس از صف، شناسه ۱۶حرفی id در state را در approve_id وارد کنید.

صف و لاگ: https://github.com/nimania/pendar/blob/nashani-state/nashani/state.json
